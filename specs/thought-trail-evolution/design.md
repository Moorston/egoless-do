## 1. 背景与目标

### 1.1 现状分析

当前系统已有基础的感念和脉络功能：

```
┌─────────────────────────────────────────────────────────────────┐
│                      当前数据模型                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   MindReflection (感念)                                         │
│   ┌──────────────────────────────────────┐                      │
│   │ id, content, tags[], mood            │                      │
│   │ timestamp, colors, isPinned          │                      │
│   │ linkedPlanItemId? (关联计划任务)       │                      │
│   │ thoughtTrailIds?[] (所属脉络)         │                      │
│   └──────────────────────────────────────┘                      │
│                    │                                            │
│                    │ 1:N (有序)                                 │
│                    ▼                                            │
│   ThoughtTrail (思路脉络)                                       │
│   ┌──────────────────────────────────────┐                      │
│   │ id, name, description?               │                      │
│   │ reflectionIds[] (有序)               │                      │
│   └──────────────────────────────────────┘                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**现有功能**：
- 基础的感念记录（内容、标签、心情、颜色）
- 思路脉络创建（手动选择感念）
- 时间线展示（简单的时间排序）
- 标签脉络（按标签聚合）

**现有局限**：
- 脉络只有顺序，没有语义连接
- 没有自动发现机制
- 缺乏复盘分析功能
- 与习惯/计划/打卡系统联动弱

### 1.2 目标定位

从「记录工具」演进为「思维伙伴」：

```
┌─────────────────────────────────────────────────────────────────┐
│                      角色转变                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  当前：记录工具                                                  │
│  用户记录 → 系统存储 → 用户回顾                                  │
│  价值：保存记忆                                                  │
│                                                                 │
│  目标：思维伙伴                                                  │
│  用户记录 → 系统分析 → 洞察反馈 → 行动指导 → 用户行动            │
│       ▲                                              │          │
│       └──────────────────────────────────────────────┘          │
│  价值：促进成长                                                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 核心价值主张

1. **看见自己** — 帮助用户发现思维模式和盲点
2. **理解自己** — 理解情绪和行为背后的原因
3. **指导行动** — 将洞察转化为可执行的方案
4. **持续成长** — 形成思考-行动-反馈的闭环

## 2. 核心设计理念

### 2.1 复盘的心理动因

什么会让人产生「回顾过去」的冲动：

1. **发现变化** — "我居然是这样走过来的"（意外感、惊喜）
2. **看见模式** — "原来我一直在重复这个循环"（自我觉察）
3. **确认成长** — "我现在比那时候强多了"（成就感、信心）
4. **理解自己** — "原来我当时是这样想的"（自我接纳）
5. **获得力量** — "那次那么难都过来了"（韧性、勇气）

**设计启示**：不是「展示数据」，而是「讲述故事」

### 2.2 复盘的三个层次

```
┌─────────────────────────────────────────────────────────────────┐
│                      复盘金字塔                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                       ┌─────────────┐                           │
│                       │   转化层    │  将洞察变成行动             │
│                       │  Transform  │                           │
│                       └──────┬──────┘                           │
│                              │                                  │
│                  ┌───────────┴───────────┐                      │
│                  │       理解层          │  发现模式和原因        │
│                  │     Understand        │                      │
│                  └───────────┬───────────┘                      │
│                              │                                  │
│          ┌───────────────────┴───────────────────┐              │
│          │             记录层                    │  描述发生了什么│
│          │             Record                    │              │
│          └───────────────────────────────────────┘              │
│                                                                 │
│  大多数app停留在记录层                                           │
│  我们要帮助用户到达理解层和转化层                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 设计原则

1. **故事性 > 列表性** — 用叙事方式展示脉络，不是平铺列表
2. **连接有语义** — 每条连接都有故事（引发、演进、转折、确认）
3. **情绪可视化** — 一眼看到「心路」变化
4. **时间有呼吸感** — 密集思考期紧凑，沉默期留白
5. **渐进式披露** — 默认简单，复杂功能按需展开
6. **自动 > 手动** — 系统能做的不让用户做
7. **轻量交互** — 连接感念：1次点击 + 1次选择

## 3. 数据模型设计

### 3.1 核心概念：意图 Intent

**为什么需要「意图」**：
- 感念是「想法」，但想法如何变成「行动」？
- 计划是「任务」，但任务背后的「为什么」是什么？
- 习惯是「行为」，但行为背后的「动机」是什么？

意图是连接「思考」和「行动」的桥梁。

### 3.2 完整数据模型

```
┌─────────────────────────────────────────────────────────────────┐
│                      数据关系图                                  │
├─────────────────────────────────────────────────────────────────┤
```

### 3.4 连接类型 LinkType

```typescript
type LinkType = 
  | 'inspire'   // 引发/启发
  | 'evolve'    // 演进/深化
  | 'contrast'  // 对比/转折
  | 'respond'   // 回应/反思
  | 'related'   // 相关/类似
```

## 7. AI辅助设计

### 7.1 AI的角色定位

**不是**：
- ✗ 替用户思考
- ✗ 给出标准答案
- ✗ 评判用户
- ✗ 过度打扰

**而是**：
- ✓ 帮助用户看见盲点
- ✓ 发现用户自己没注意到的模式
- ✓ 引导用户深入思考
- ✓ 在关键时刻提供视角
- ✓ 降低记录和反思的门槛

### 7.2 AI应用场景

#### 7.2.1 感念捕捉时

1. **智能标签建议** — 基于内容分析推荐标签
2. **情绪识别与深化** — 帮助用户更精确地识别情绪
3. **内容扩展引导** — 简短内容时引导深入

#### 7.2.2 脉络构建时

1. **自动脉络发现** — 基于语义相似度、时间聚类、情绪轨迹
2. **脉络洞察生成** — 分析转折点、应对策略、延伸思考

#### 7.2.3 意图与行动时

1. **意图提炼** — 从脉络中提炼可能的意图
2. **计划生成** — 基于用户历史数据设计计划
3. **风险预警** — 基于历史习惯养成数据预测风险

#### 7.2.4 复盘时

1. **引导式对话** — 像智慧的朋友在对话
2. **深度提问** — 基于用户数据问好问题

#### 7.2.5 日常使用

1. **情境感知提醒** — 基于情境的智能提醒
2. **打卡时洞察** — 即时反馈和鼓励

### 7.3 AI技术架构

```
┌─────────────────────────────────────────────────────────────────┐
│  Layer 1: 本地轻量级AI                                           │
│  • 关键词提取、情绪词典匹配、标签建议、时间模式分析、简单统计     │
│  • 技术：规则引擎 + 本地词典 + 统计分析                          │
│  • 特点：零延迟、零成本、完全离线                                 │
├─────────────────────────────────────────────────────────────────┤
│  Layer 2: 本地小型模型（可选）                                    │
│  • 语义相似度、内容分类、情感分析、实体提取                       │
│  • 技术：小型embedding模型（如MiniLM）                           │
│  • 特点：低延迟、低资源消耗、离线可用                             │
├─────────────────────────────────────────────────────────────────┤
│  Layer 3: 云端大模型（用户授权）                                  │
│  • 深度洞察、对话式复盘、复杂模式识别、个性化建议                 │
│  • 技术：调用大模型API                                           │
│  • 特点：能力强、需要网络、需要用户授权                           │
│  • 注意：数据最小化、不上传原文、只上传摘要                       │
└─────────────────────────────────────────────────────────────────┘
```

### 7.4 AI的边界与克制

1. 用户可以完全不用AI — 所有AI功能都是可选的
2. AI建议可以忽略 — 每个建议都有「忽略」选项
3. AI不会评判 — 用中性的语言，不说「你应该」
4. AI不会过度打扰 — 提醒频率有上限
5. 隐私是底线 — 默认离线处理，云端需要授权

## 9. 待优化与补充

### 9.1 数据层面

1. **历史数据迁移** — 现有的 ThoughtTrail 如何平滑迁移到新模型
2. **数据一致性** — 多实体关联时的一致性保证
3. **离线同步** — 新增实体的离线同步策略
4. **数据清理** — 意图、脉络的归档和清理策略

### 9.2 用户体验层面

1. **新手引导** — 如何让新用户理解脉络和意图的价值
2. **冷启动问题** — 新用户没有历史数据，自动脉络发现无法工作，需要设计引导流程让用户快速体验到价值（如：引导用户记录3-5条感念后，展示第一个自动发现的脉络）
3. **操作复杂度** — 平衡功能丰富和操作简单
4. **性能考虑** — 大量感念时的渲染和分析性能
5. **多平台一致性** — 移动端和Web端的体验一致性

### 9.3 功能边界

1. **脉络的粒度控制** — 如何避免脉络过多或过少，需要设计智能聚合策略（如同一主题的脉络可以合并）
2. **复盘的触发时机** — 什么时候邀请用户复盘最合适？太频繁会打扰，太少会遗忘。建议策略：
   - 每周日晚固定邀请（可关闭）
   - 检测到情绪明显转变时邀请
   - 完成一个意图/习惯时邀请
   - 用户可设置偏好频率
3. **意图的生命周期管理** — 意图长期不活跃怎么办？需要设计超时和提醒机制：
   - 种子状态超过7天未进展 → 提醒用户是否要行动或放弃
   - 活跃状态超过30天未完成 → 提醒用户检视进度
   - 用户可手动归档或关闭意图
4. **AI建议的频率** — 如何平衡有用和打扰
5. **自动 vs 手动** — 哪些该自动，哪些该手动
6. **隐私边界** — 哪些数据可以用于AI分析

### 9.4 商业化考虑

1. **免费 vs 付费** — AI功能是否作为付费特性
2. **成本控制** — 云端AI调用的成本控制
3. **数据所有权** — 用户数据的导出和删除

### 9.5 技术风险

1. **本地AI性能** — 移动端运行AI模型的性能影响
2. **电池消耗** — 后台分析对电池的影响
3. **存储占用** — 新增数据结构的存储开销

### 9.6 可补充的功能点

1. **脉络分享** — 将脉络生成精美卡片分享到社交媒体
2. **脉络模板** — 预设的脉络类型（如「21天习惯养成」「项目复盘」）
3. **多人脉络** — 与他人共享脉络（如情侣、团队）
4. **脉络对比** — 对比不同时期的脉络（如「这个月 vs 上个月」）
5. **语音记录** — 语音转文字记录感念
6. **定期报告** — 自动生成周报/月报
7. **成就系统** — 完成脉络、达成意图的成就徽章
8. **社区功能** — 匿名分享脉络，获取他人反馈
