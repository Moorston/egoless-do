# AI 集成规划

**Branch**: `20260606-ai-integration-plan` | **Date**: 2026-06-06

## 背景

egoless-do（心流纪）是一个隐私优先的修行打卡应用，当前没有任何 AI/ML 集成。i18n 字符串中已预留了 "AI insights"、"AI 感悟总结" 等 Premium 功能文案，但均未实现。

本规格分析项目如何接入并使用 AI，确定最佳集成方案。

## 用户需求

1. **感念总结与洞察** - 对用户的感念/反思日记进行 AI 分析，生成情绪趋势洞察、主题总结
2. **语义相似度** - 为思路脉络（Thought Trails）提供语义关联推荐
3. **饮食分析** - 基于食物记录提供营养建议
4. **习惯洞察** - 基于打卡和习惯数据提供个性化建议
5. **运动分析** - 基于 GPS 和运动数据提供训练建议

## 约束

- **隐私优先**: 用户数据本地优先（SQLite/AsyncStorage/Dexie），AI 处理需尊重隐私
- **离线友好**: 不能强依赖网络连接
- **成本可控**: 作为个人项目，需考虑 API 调用成本
- **跨平台**: 方案需同时支持 Mobile（React Native）和 Web（Next.js）
- **渐进式**: 可以分阶段实施，先实现核心价值最高的功能

## 验收标准

- [ ] 确定 AI 服务提供商和接入方式
- [ ] 确定架构方案（客户端直连 vs 服务端代理 vs 混合）
- [ ] 确定数据隐私保护策略
- [ ] 定义 AI 功能的优先级和分阶段路线图
- [ ] 设计 API 接口契约
- [ ] 设计数据模型扩展
