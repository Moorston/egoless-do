# 项目功能需求分析

## 项目概述

**心流纪 · Egoless Do** — 跨平台正念修行 + 习惯追踪 + 思维记录综合应用。

帮助用户养成健康饮食、规律冥想、运动习惯，同时捕捉内心感悟，实现身、心、思全面提升。

## 技术架构

### 前端 (Mobile)
- **框架**: React Native + Expo
- **状态管理**: Zustand
- **本地存储**: SQLite (expo-sqlite)
- **安全存储**: expo-secure-store

### 后端 (API)
- **框架**: Hono (Node.js)
- **数据库**: PocketBase (SQLite)
- **认证**: JWT + Refresh Token
- **安全**: Rate limiting, CSP, CORS

### 数据流
```
用户操作 → Screen → Slice Action → StorageAdapter → SQLite
                                        ↓
                                  SyncEngine → PocketBase
```
