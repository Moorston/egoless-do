# PRD: 调身计划新建页保存/开始训练按钮无法点击 + 模块硬编码全量修复

## 问题描述
1. 调身计划新建页，用户完成填写后「保存方案」和「开始训练」按钮仍 disabled

3. 扩展：调身模块 31 个文件共 110 个硬编码/假国际化问题
