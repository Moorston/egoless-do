## 当前 UI 的问题

### 1. 信息层级混乱

```
📋 今日方案
🏋️ 胸+三头
  🏋️ 杠铃卧推 4×10     ← 动作列表（白色文字，15%透明背景）
  🏋️ 哑铃飞鸟 3×12
  ┌ ─ ─ ─ ─ ─ ─ ─ ┐
  │  🏃──🌬️──🧠     │   ← flow 进度（同样 15%透明背景）
  │    调息安神      │
  └ ─ ─ ─ ─ ─ ─ ─ ┘
[▶ 继续]
```

**问题**：动作列表和 flow 进度指示器使用相同的背景色（`rgba(255,255,255,0.15)`），视觉上难以区分。用户可能分不清哪个是动作列表、哪个是进度条。

### 2. Flow 进度指示器 UI 太简陋

```
   🏃 ─── 🌬️ ─── 🧠
       调息安神
```

- 3 个 32px 的圆点，间距小
- 连接线只有 20px 宽，2px 高
- 无文字标签（只有当前步骤名称在下面）
- 无法点击（不能跳转到指定步骤）
- 完成状态使用 ✓ 替代 emoji，但视觉上差不多

### 3. 动作列表与 flow 进度争抢空间

当 flow 活跃时，banner 中同时显示：
- 动作列表（今日计划中的动作）
- Flow 进度指示器（3 步状态）
- "继续"按钮

空间有限（banner 高度固定），信息过于密集。

### 4. 按钮文案单一

- 无 flow 时：「开始今日训练」
- 有 flow 未完成：「继续」
- 全部完成：无按钮

「继续」没有说明继续做什么（继续运动？继续调息？继续觉知？）。

### 5. 休息日卡片内容弱

```
😴 今日休息
[🧘 行走] [🧘‍♀️ 瑜伽] [🌬️ 调息]
```

休息日的建议按钮点击后直接进入 BodyFlow，但用户可能只是想单独做某个活动，不想走完整的三步流程。

### 6. 无进度百分比

用户看不到整体完成进度（比如"已完成 2/3 步"），只有一个模糊的圆点指示器。

## Flow 进度指示器详细分析

### 当前实现

```
位置：今日方案 banner 内，动作列表下方
触发条件：hasActiveFlow && !allFlowDone
          即 flowState 有值且 24 小时内未过期
          且不是全部完成

结构：
  3 个圆点（32px）：🏃(未完成) / ✓(完成)  🌬️(未完成) / ✓(完成)  🧠(未完成) / ✓(完成)
  2 条连接线（20px × 2px）
  下方文字：当前步骤名称（"调身练习" / "调息安神" / "记录感受"）

数据源：
  flowState.exerciseCompleted
  flowState.breathingCompleted
  flowState.awarenessCompleted

样式：
  圆点背景色：完成 = rgba(255,255,255,0.3)  未完成 = rgba(255,255,255,0.15)
  连接线：rgba(255,255,255,0.2)
  文字：FONT_SMALL, rgba(255,255,255,0.8)
```

### 缺陷

1. **无标签**：圆点没有文字标签，用户必须记住🏃=运动、🌬️=调息、🧠=觉知
2. **无交互**：不能点击圆点跳转到对应步骤
3. **无进度量化**：不知道完成了百分之几
4. **样式单一**：所有圆点大小相同，无当前步骤高亮
5. **与动作列表视觉冲突**：相同背景色，用户可能忽略

## 优化方案

### 方案 A：轻量优化（最小改动）

```
📋 今日方案
🏋️ 胸+三头
  🏋️ 杠铃卧推 4×10
  🏋️ 哑铃飞鸟 3×12

  ✅ 调身练习  ───  🌬️ 调息安神  ───  🧠 记录感受
       已完成             进行中              待开始

  [▶ 继续调息]
```

改动：
1. 圆点改为带文字标签的步骤条（类似 ExerciseProgressBanner 的样式）
2. 完成步骤显示 ✅ + 名称，当前步骤高亮，未完成步骤灰色
3. 按钮文案改为「继续调息」/「继续觉知」等具体步骤名
4. 动作列表和进度条之间增加视觉分隔（线或间距）

### 方案 B：中等优化（整合动作列表）

```
📋 今日方案
┌────────────────────────────────────┐
│  ✅ 调身练习    已完成 15:30       │
│     🏋️ 杠铃卧推 4×10              │
│     🏋️ 哑铃飞鸟 3×12              │
├────────────────────────────────────┤
│  🌬️ 调息安神    当前步骤           │
│     运动后调息有助于恢复身心平衡   │
├────────────────────────────────────┤
│  🧠 记录感受    待开始             │
└────────────────────────────────────┘
[▶ 开始调息]
```

改动：
1. 将 3 步流程改为垂直堆叠的卡片式步骤条
2. 每个步骤显示状态（完成/当前/待开始）
3. 已完成步骤显示动作列表
4. 当前步骤显示描述文字
5. 按钮文案对应当前步骤

### 方案 C：大改（flow 独立面板）

从 banner 中移出 flow 进度，改为独立面板：

```
┌──────────────────────────────────────┐
│  📋 今日方案          [运动记录]     │
│  🏋️ 胸+三头                         │
│    🏋️ 杠铃卧推 4×10                 │
│  [▶ 开始今日训练]                    │
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│  📊 今日训练进度      2/3 完成       │
│                                      │
│  ✅ 调身练习    15:30   🏋️ 5个动作  │
│  ⏳ 调息安神    —                     │
│  ⏳ 记录感受    —                     │
│                                      │
│  [▶ 继续调息]                        │
└──────────────────────────────────────┘
```

改动：
1. 今日方案 banner 保持简洁，只显示计划
2. flow 进度从 banner 中分离，成为独立卡片
3. 进度卡片显示详细步骤状态、时长、数据
4. 可点击步骤跳转

## 推荐方案

**推荐方案 B**，理由：
1. 信息层级清晰：垂直排列的 3 步一目了然
2. 无需新增独立卡片，不增加页面复杂度
3. 动作列表自然融入已完成步骤中，不重复
4. 按钮文案可以对应当前步骤
5. 改动量适中，不需要重构 banner 架构
