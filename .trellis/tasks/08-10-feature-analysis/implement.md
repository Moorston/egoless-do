## 数据流

```
┌─────────────────────────────────────────────────────────────┐
│                      音乐浏览流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  用户打开音乐库                                              │
│       │                                                     │
│       ▼                                                     │
│  MusicLibraryScreen                                         │
│       │                                                     │
│       ├─→ 显示分类卡片                                       │
│       ├─→ 显示最近下载                                       │
│       └─→ 搜索栏                                            │
│                                                             │
│  用户选择分类                                                │
│       │                                                     │
│       ▼                                                     │
│  MusicCategoryScreen                                        │
│       │                                                     │
│       ├─→ 加载曲目列表                                       │
│       ├─→ 显示下载状态                                       │
│       └─→ 预览/下载按钮                                      │
│                                                             │
│  用户点击预览                                                │
│       │                                                     │
│       ▼                                                     │
│  PreviewPlayer                                              │
│       │                                                     │
│       ├─→ 播放30秒预览                                       │
│       └─→ 显示播放控制                                       │
│                                                             │
│  用户点击下载                                                │
│       │                                                     │
│       ▼                                                     │
│  MusicDownloadManager                                       │
│       │                                                     │
│       ├─→ 开始下载                                          │
│       ├─→ 更新进度                                          │
│       └─→ 完成通知                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 版权问题 | 高 | 使用 CC0 音乐，审核所有曲目 |
| 存储空间 | 中 | 限制下载数量，提供清理功能 |
| 网络问题 | 中 | 支持断点续传，离线可用 |
| 用户体验 | 中 | 提供预览，避免下载不喜欢的音乐 |
