# 周计划运动选择 UX 优化：一体化网格布局

## Goal
将新建调身计划页的两步选择流程（先选类别 → 再选动作）重构为一体化的分组网格视图，减少用户操作步骤，提升选择效率。

## Background
当前流程：
1. 用户点击某天 → 显示类别 chips（传统/现代/自由）
2. 用户点击某类别 → 显示该类别动作列表（多选 chips）
3. 用户点击"添加选中的 N 个动作"添加到计划

问题：步骤多、动作列表无视觉层次、搜索位置反直觉、数量角标太小。

## 设计方案：一体化网格

### 新流程
1. 用户点击某天 → **直接显示分组动作网格**（无需先选类别）
2. 顶部有搜索栏，实时过滤全部分组
3. 按类别分组展示（类别标题带 icon + 颜色标识）
4. 每个动作是一个卡片（icon + 名称 + 组数×次数），点击即多选
5. 已添加到该天的动作显示 ✓ 并 dimmed
6. 底部浮动工具栏显示"已选 N 个" + 确认按钮

### 视觉设计

**类别区头 (Category Header)**
- 左侧：类别 icon (24px)
- 中左：类别名称 (FONT_SUB, 600 weight, 类别主题色)
- 右侧：可选 `已添加 X/Y`
- 浅色背景条 (类别色 10% opacity) 或纯背景分隔

**动作卡片 (Exercise Card)**
- 宽度：自适应网格 (`flexWrap`，每个 item `width: '30%'` 或类似)
- 内边：10px
- 圆角：10px
- 未选中态：`backgroundColor: TH.card`, `borderWidth: 1, borderColor: TH.border`
- 选中态：`backgroundColor: ${P}18`, `borderColor: P, borderWidth: 2`
- 已添加态：`opacity: 0.45`, 左上角 ✓ 标记
- 文字：`ex.nameZh` (FONT_SMALL), 如果有 `defaultSets × defaultReps` 则显示

**搜索栏**
- 位置：activeDay 展开区域的顶部（替代当前底部的位置）
- 样式：与现有搜索框一致（Search icon + TextInput + 清除按钮）
- 实时过滤：搜索时跨类别匹配 `nameZh`

**底部工具栏 (Selection Bar)**
- 在 exercise grid 下方
- 显示：左侧已选数量 `已选 N 个`，右按钮 `添加到计划`
- 已选 0 个时按钮 disabled

**休息日**
- 保留休息 😴 选项（放在最前面或顶部独立按钮）

## Requirements
- **R1**: 重构 `BodyPlanEditorScreen` 的运动选择区域，替换现有的两步 chips 流程为一体化分组网格
- **R2**: 搜索栏在网格顶部（非底部）
- **R3**: 动作卡片宽度自适应（每行 2-3 个）
- **R4**: 已添加的动恙显示状态（dimmed + checkmark）
- **R5**: 底部浮动工具栏显示已选数量 + 确认按钮
- **R6**: 保留休息日选项

## Acceptance Criteria
- [ ] A1: 用户选择某天，直接看到分组动作网格（无需先选类别）
- [ ] A2: 搜索栏位于动作网格顶部，实时过滤
- [ ] A3: 动作以卡片形式展示（icon + 名称 + sets×reps）
- [ ] A4: 点击动作卡片即切换选中状态，视觉反馈明显
- [ ] A5: 已添加到该天的动作显示 dimmed + ✓
- [ ] A6: 底部显示已选数量 + 确认按钮
- [ ] A7: 周计划其余功能（日期选择、目标填写、_template 选择）不受影响
- [ ] A8: 342 测试全过

## Out of Scope
- 运动类别 icon/颜色的重新设计
- 动作预览详情（如视频、描述）
- 已添加动作的移除/替换交互（保持现有通过 day dot 重置行为）
