## Goal

将调眠页首页从信息卡片堆叠式布局，重构为信息层级清晰、交互丰富的睡前体验页面，提升用户记录睡眠的意愿和睡前仪式的参与感。

用户价值：更顺手的睡眠记录入口 + 一眼可见的趋势/连续记录，降低睡前记录门槛。

## Requirements（已实现）

### R1: 视觉基调
- 原 PRD 要求「统一的夜间色彩体系 + 深色渐变背景 + 专属夜间视觉语言」。
- **实际落地**：采用全局主题色（`TH.bg` / `TH.card` / `TH.primary`），而非独立的 `#0a0a1a` 深色背景。
- **决策（已提交）**：刻意改为主题色，保证与全局主题系统一致、避免双套视觉语言。PRD 的「沉浸夜间氛围」目标降级为「主题一致的深色友好界面」。

### R2: 信息架构
- 昨晚睡眠卡片置顶（时长 + 质量评分 + 时间轴 + 仪轨状态）。
- 连续记录天数在显眼位置（StreakBar）。
- 十二时辰卡保留并增强交互。
- 睡眠目标卡支持编辑。

### R3: 交互增强
- 十二时辰：每个时辰圆点可点击 → 详情 Modal（时辰名 / 脏腑 / 养生建议 / 时段）。
- 睡眠目标：编辑 Modal（目标入睡 / 起床 / 时长）。
- 快速日记：首页直接评分 + 工作状态，降低填写门槛。

### R4: 数据可视化
- 首页本周 7 天趋势 mini chart（纯 `View` 实现柱状图，颜色随质量/时长变化）。
- 无需跳转历史页即可看趋势；点击柱子弹出当天详情。

### R5: 快速日记入口
- 首页直接 5 星评分 + 4 选 1 工作状态，保存调用 `saveSleepDiary`。
- 完整日记 Modal 仍保留。
