# 调眠页首页功能与设计优化

## Goal

将调眠页首页从当前的信息卡片堆叠式布局，重构为沉浸式、信息层级清晰、交互丰富的睡前体验页面，提升用户记录睡眠的意愿和睡前仪式的参与感。

## Background

### 当前首页布局（从上到下）
1. SimpleHeader（logo + streak + 日期）
2. 十二时辰卡（当前时辰 + 脏腑 + 建议 + 12 圆点时间线 + 倒计时）
3. 睡眠目标卡（目标入睡/起床/时长，静态展示）
4. 今日日记卡（昨晚数据标签 / 填写入口按钮）
5. 调眠仪轨卡（深色背景，15/20/30 分钟按钮 + 快速感恩）
6. 最近记录列表（有数据时显示）
7. 查看睡眠历史按钮
8. 连续记录天数（最底部）

### 当前问题
- 信息层级平：所有卡片等大等距，没有视觉重点
- 十二时辰交互弱：12 个圆点尺寸太小，不可点击，信息密度低
- 色彩不统一：仪轨卡深色背景与其他卡片风格断裂
- 缺乏夜间氛围：没有独特的睡前沉浸体验
- 关键数据不突出：昨晚睡眠数据藏在中间，连续记录在底部
- 趋势不可见：查看趋势必须跳转到历史页
- 日记填写门槛高：必须打开弹窗，7 个字段较多

## Requirements

### R1: 视觉氛围（夜间沉浸感）
- 统一的夜间色彩体系（紫色/靛蓝主色调、柔光效果）
- 调眠页应有区别于其他页面的独特视觉语言
- 深色渐变背景，配合睡前场景氛围

### R2: 信息架构重构
- 昨晚睡眠数据放在最顶部（时长 + 质量评分 + 时间轴 + 仪轨状态）
- 连续记录天数放在显眼位置（底部，与趋势图相邻）
- 十二时辰卡保留但增强交互性
- 睡眠目标卡保留但支持编辑
- 最近记录列表可精简（趋势图替代部分功能）

### R3: 交互增强
- 十二时辰：每个时辰可点击，弹出详情（脏腑、养生建议、适合修行）
- 睡眠目标：点击编辑弹窗
- 快速日记：首页直接放质量评分 + 工作状态选择，降低填写门槛

### R4: 数据可视化
- 首页增加本周睡眠趋势 mini chart（柱状图或折线图，颜色随质量变化）
- 无需跳转历史页即可查看趋势

### R5: 快速日记入口
- 日记填写入口更突出
- 常用选项（质量评分、工作状态）可放在首页直接操作
- 完整日记弹窗保留

## Acceptance Criteria

- [ ] 首页视觉风格统一为夜间氛围，紫色/靛蓝主色调
- [ ] 昨晚睡眠卡片在页面顶部，展示时长、质量、时间轴、仪轨状态
- [ ] 十二时辰卡片可点击交互，点击弹出详情
- [ ] 睡眠目标卡片支持编辑
- [ ] 本周睡眠趋势图（至少 7 天柱状图）
- [ ] 连续记录天数在显眼位置
- [ ] 调眠仪轨入口保持突出
- [ ] 快速日记入口（质量评分 + 工作状态）在首页可直接操作
- [ ] 完整日记弹窗仍然保留
- [ ] 原有功能（仪轨流程、感恩、报告）不受影响

## Out of Scope
- 仪轨流程页面（barrier/gratitude/report）的设计优化
- 日记弹窗的优化
- 历史页的优化
- 夜间模式主题切换（已有全局主题系统）

## 已确认的决策
- 方向：A（视觉氛围）+ B（信息架构）+ C（交互增强）+ D（数据可视化）+ E（快速日记）全部包含
- 优先级：首页优先，其他页面后续
