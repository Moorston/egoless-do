# 打卡复盘系统 - 功能测试指南

## 测试环境准备

1. 确保应用已安装并运行
2. 确保有打卡历史数据
3. 确保有习惯和计划数据
4. 确保AI服务已配置

## 测试用例

### 1. 周复盘功能

#### 1.1 切换到周复盘Tab
- **步骤**: 打开打卡历史页面 → 点击"周复盘"Tab
- **预期**: 显示加载动画 → 显示本周复盘数据

#### 1.2 核心指标显示
- **预期**: 
  - 完成率正确显示（百分比）
  - 连续天数正确显示
  - 对比上期数据正确显示（百分比变化）

#### 1.3 未完成分析
- **预期**: 
  - 显示未完成原因分布
  - 显示未完成项列表
  - 数据准确

#### 1.4 习惯养成进度
- **预期**: 
  - 显示所有进行中的习惯
  - 进度条正确显示
  - 完成天数/目标天数正确
  - 连续天数正确

#### 1.5 计划任务进度
- **预期**: 
  - 显示所有进行中的计划
  - 进度条正确显示
  - 已完成任务数/总任务数正确

#### 1.6 健康指标
- **预期**: 
  - 体重、饮水、热量、运动等指标正确显示
  - 对比上期变化正确显示

#### 1.7 AI分析
- **预期**: 
  - 显示AI生成的总结文案
  - 显示亮点列表
  - 显示改进建议列表
  - 文案内容专业且有建设性

#### 1.8 历史复盘入口
- **预期**: 
  - 显示最近3条历史复盘
  - 点击"查看全部"跳转到历史页面

#### 1.9 下拉刷新
- **步骤**: 下拉刷新
- **预期**: 重新生成复盘数据

### 2. 月复盘功能

#### 2.1 切换到月复盘Tab
- **步骤**: 点击"月复盘"Tab
- **预期**: 显示加载动画 → 显示本月复盘数据

#### 2.2 数据准确性
- **预期**: 
  - 日期范围为本月1日到月末
  - 完成率基于本月数据计算
  - 习惯进度基于本月数据计算

### 3. 复盘历史功能

#### 3.1 查看历史复盘
- **步骤**: 点击"查看全部"或从打卡历史页面进入
- **预期**: 显示复盘历史页面

#### 3.2 切换周/月Tab
- **步骤**: 点击"周复盘"或"月复盘"Tab
- **预期**: 显示对应类型的历史复盘列表

#### 3.3 按月份分组
- **预期**: 
  - 复盘按月份分组显示
  - 每组显示月份标题和数量

#### 3.4 点击查看详情
- **步骤**: 点击某个复盘记录
- **预期**: 跳转到复盘详情页面（待实现）

### 4. 自动生成功能

#### 4.1 周日自动生成
- **条件**: 今天是周日
- **预期**: 自动生成上周复盘

#### 4.2 月末自动生成
- **条件**: 今天是月末
- **预期**: 自动生成本月复盘

### 5. 数据同步功能

#### 5.1 复盘数据持久化
- **预期**: 
  - 复盘数据保存到本地存储
  - 应用重启后数据不丢失

#### 5.2 云端同步
- **预期**: 
  - 复盘数据同步到PocketBase
  - 多设备数据一致
