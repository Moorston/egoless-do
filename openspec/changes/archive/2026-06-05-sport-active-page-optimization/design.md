## Context

当前 `SportPage.tsx` 中非GPS运动的 active 阶段存在以下问题：
- 布局扁平：主数字、控制按钮、时长、目标进度堆在同一垂直轴
- 自由模式空旷：无目标进度、无引导，页面大部分空白
- 信息重复：卡路里在主区和底部栏都显示
- MET 值无意义：普通用户不理解 MET
- 缺少音效：运动中无背景音、无呼吸引导
- 休息页面简单：仅大数字+跳过按钮

项目已有资源：
- `expo-audio` + 环境音效（海潮、雨声、钵声、鸟叫、流水、风铃）在冥想模块中
- `expo-haptics` 已安装
- `react-native-svg` 已安装

## Goals / Non-Goals

**Goals:**
- 三区布局提升信息层级
- 音效陪练系统（环境音 + 呼吸引导 + 事件音效）
- 瑜伽/太极呼吸引导动画
- 软目标系统（自由模式推荐时长/次数）
- 去重信息、移除无意义数据
- 视觉增强（渐变、动效、涟漪）
- 休息页面升级

**Non-Goals:**
- GPS 运动页面
- 社交功能
- 自定义音效上传
- Apple Music / Spotify 集成

## Decisions

### 1. 运动体验分类

将运动按体验分为 4 类，每类有不同的 UI 策略：

| 类型 | 运动 | 主显示 | 音效 | 特色功能 |
|------|------|--------|------|----------|
| 冥想型 | 瑜伽/太极/铁牛 | 呼吸动画+时长 | 环境音+呼吸音 | 呼吸引导 |
| 耐力型 | 游泳/爬楼梯 | 倒计时/时长 | 环境音可选 | 进度条 |
| 力量型 | 俯卧撑/深蹲 | 次数 | 可选 | 组历史+长按 |
| 间歇型 | 波比跳/开合跳 | 次数 | 鼓点节奏 | 嵌入式休息 |

### 2. 音效系统架构

三层音频同时播放，独立控制：

```
Layer 1: 环境音 (expo-audio, loop, vol 0.2-0.3)
  - 复用冥想音效: 海潮/雨声/钵声/鸟叫/流水/风铃
  - 新增运动音效: 森林/溪流/篝火/鼓点节奏
  - 底部迷你栏 ♫ 图标，点击展开选择

Layer 2: 呼吸引导音 (timed one-shot, vol 0.4-0.5)
  - 吸气开始: 轻柔钵声 "叮~"
  - 呼气开始: 低沉钟声 "咚~"
  - 节奏: 4-4-4 或 4-7-8 可配置

Layer 3: 事件音效 (one-shot, vol 0.5-0.6)
  - 组完成: 清脆 "叮！" + haptic
  - 目标达成: 欢快旋律 + haptic success
  - 软目标达成: 温和 "叮~" + 轻震动
```

实现：复用 `MeditationScreen` 的 `useAudioPlayer` 模式。

### 3. 呼吸引导动画

状态机：吸气(4s) → 屏息(4s) → 呼气(4s) → 循环

视觉效果：
- 外圈：Animated scale 0.6 → 1.2 → 0.6
- 背景色：蓝→绿→蓝 渐变
- 文字："吸气..." → "屏住..." → "呼气..."
- 进度点：4 个小圆点，当前阶段高亮

实现：3 个 `Animated.timing` 串联 + 循环。

### 4. 软目标系统

数据来源优先级：
1. 用户历史平均值（最近 5 次同运动）
2. 运动推荐表（packages/core 中配置）
3. 用户手动设置（准备页可选）

推荐表存放在 `packages/core/src/constants.ts`，格式：
```typescript
export const SOFT_TARGETS: Record<string, { beginner: number; intermediate: number; advanced: number; unit: string }> = {
  '瑜伽': { beginner: 15, intermediate: 30, advanced: 60, unit: 'min' },
  '俯卧撑': { beginner: 30, intermediate: 60, advanced: 100, unit: 'reps' },
  // ...
};
```

UI：自由模式显示 "💡 建议 30 分钟" + 柔和进度条，达成时温和反馈。

### 5. 信息架构

移除项：
- MET 显示（替换为更有意义的信息）
- 主区卡路里（仅底部栏显示）

新增项：
- 软目标推荐 + 进度条
- 呼吸引导动画（冥想型）
- 音效控制栏
- 里程碑激励文案

### 6. 视觉增强

- 背景渐变：根据运动类型使用不同色调
- 主数字微弹：每次变化 scale 1.0 → 1.05 → 1.0
- 按钮涟漪：+1 绿色、-1 红色涟漪扩散
- 进度条：渐变色 + 脉冲光
- 里程碑：金色闪光 + 放大

### 7. 休息页面

两种模式：
- **全屏休息**（力量型）：环形倒计时 + 上一组/下一组信息
- **嵌入式休息**（间歇型）：休息进度条嵌入主页面，显示下一组目标

### 8. 暂停页增强

- 显示运动数据摘要（时长/次数/卡路里）
- 直接结束按钮（移除长按）
- 新增退出按钮（不保存）
- 音效控制

### 9. 准备页联动

新增控件：
- 音效选择器（环境音下拉）
- 呼吸引导开关（冥想型默认开）
- 软目标推荐显示
- 上次运动数据

## Risks / Trade-offs

- **音效文件大小** → 新增 4-6 个 .mp3 文件，约 2-3MB，可接受
- **呼吸引导精度** → setTimeout 有 ±16ms 误差，呼吸场景可接受
- **音频焦点** → 需处理其他 app 音频冲突（expo-audio 的 audioMode 配置）
- **长按误触** → 200ms 延迟 + 标志位区分短按/长按
- **动画性能** → 使用 Animated API，不引入 reanimated
