## Context

感念页面（ReflectionsScreen）是用户记录内心感悟的核心入口，当前支持：
- 渐变色卡片展示，按日期分组
- 搜索、筛选（标签/心情）
- 长按操作菜单（编辑、创建计划任务、删除）

现有痛点：
- 缺乏将相似想法关联起来的机制
- 无法追踪一个问题的解决过程
- 无法回顾某个主题的心路历程

## Goals / Non-Goals

**Goals:**
- 提供思路脉络功能，让用户手动创建感念关联链
- 提供标签脉络功能，基于标签自动聚合感念
- 提供独立的思维脉络页面，包含两个视图
- 支持两种创建方式（感念详情页 + 思维脉络页面）
- 支持自动命名 + 用户修改

**Non-Goals:**
- 不支持 AI 语义相似度
- 不支持时间线视图
- 不支持 Web 端

## Decisions

### 1. 数据模型设计

**决策**: 新增 `ThoughtTrail` 类型，MindReflection 新增 `thoughtTrailIds` 字段

**理由**:
- 思路脉络是独立实体，有自己的名称、描述、排序
- 一个感念可以属于多条思路脉络（多对多关系）
- thoughtTrailIds 是冗余字段，用于快速查询

**类型定义**:
```typescript
interface ThoughtTrail extends Syncable {
  id: string;
  name: string;
  description?: string;
  reflectionIds: string[];  // 有序
  createdAt: number;
  updatedAt: number;
}
```

**替代方案**:
- 在 MindReflection 中添加 relatedIds（只支持双向关联，不支持排序和命名）
- 创建单独的关联表（过度设计）

### 2. 自动命名规则

**决策**: 优先使用第一个标签，无标签时使用内容前 20 字

**理由**:
- 标签语义清晰，如 "#工作焦虑的心路历程"
- 内容前 20 字作为备选，如 "今天工作压力很大..."
- 用户可以修改，不强制

### 3. 标签脉络实现

**决策**: 复用现有标签系统，无需新增数据结构

**理由**:
- 标签已经存在于 MindReflection 中
- 只需按标签分组聚合即可
- 提供"创建为思路脉络"快捷操作

### 4. 页面结构

**决策**: 新增独立的思维脉络页面，包含两个 Tab

**理由**:
- 独立页面空间充足，可展示更丰富的内容
- Tab 切换符合用户习惯
- 复用现有筛选计算逻辑

**页面结构**:
```
MindTrailScreen
├── Header (返回 + 标题)
├── Tab 切换 (思路脉络 / 标签脉络)
├── 思路脉络 Tab
│   ├── 思路脉络列表
│   └── 新建按钮
└── 标签脉络 Tab
    ├── 标签列表
    └── 每个标签的感念列表
```

### 5. 创建流程

**决策**: 支持两种创建方式

**方式 1 - 从感念详情页**:
```
感念详情 → 添加到思路脉络 → 选择已有/新建
```

**方式 2 - 从思维脉络页面**:
```
思维脉络页 → 新建思路脉络 → 输入名称 → 选择感念
```

**理由**:
- 方式 1 适合浏览感念时自然触发
- 方式 2 适合批量操作，整体视角

### 6. 思维脉络入口卡片

**决策**: 在感念页面搜索框上方添加思维脉络入口卡片，使用浅色背景 + 左侧紫色装饰条样式

**理由**:
- 位置醒目，用户进入感念页面即可看到
- 不占用搜索和筛选区域空间
- 特殊样式与感念卡片区分，避免混淆

**设计参数**:
```
┌─────────────────────────────────────────────────────────────────┐
│  🌿 感念                                                    [+] │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────────┐   │
│  │▌  🧠  思维脉络                          查看 →         │   │
│  │       追踪思路演变 · 3 条脉络                           │   │
│  └─────────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  🔍 搜索感念...            [筛选] [📊]                  │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

**样式细节**:
- 卡片背景: TH.card，圆角 12px，边框 1px TH.border
- 左侧装饰条: 3px 宽，紫色 (#8B5CF6)，圆角 1.5px
- 图标: Brain (lucide)，20px，紫色
- 标题: FONT_BODY，600 粗细，TH.text
- 描述: FONT_SMALL，400 粗细，TH.sub
- 查看按钮: FONT_SMALL，500 粗细，紫色

**状态处理**:
- 有脉络时: 显示 "追踪思路演变 · X 条脉络"
- 无脉络时: 显示 "追踪你的思路演变，回顾心路历程"

**交互**:
- 点击整个卡片 → 导航到 MindTrail 页面
- 始终显示，不可关闭
- activeOpacity: 0.7

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|----------|
| 双向关联数据一致性 | 添加/移除时同步更新两个实体 |
| 大量思路脉络时性能 | 分页加载，虚拟列表 |
| 标签脉络与思路脉络重叠 | 两者独立，可以重叠 |

## Migration Plan

1. 新增 ThoughtTrail 类型定义
2. MindReflection 新增 thoughtTrailIds 字段
3. AppState 新增 thoughtTrails 状态
4. 新增思维脉络页面和组件
5. 添加路由配置

**回滚策略**: 移除新增字段和页面即可，不影响现有功能
