## Why

当前首页存在以下问题：
1. **打卡依赖弹窗** — CheckinModal 是一个独立弹窗，用户需要打开、填写、关闭，交互链路过长
2. **首页信息过载** — 8 个卡片纵向排列（Banner、Grace、Streak、Stats 四宫格、体重、步数、饮水、热量），首屏信息密度过高
3. **打卡与数据分离** — 体重/饮水/热量是独立卡片，与打卡流程割裂
4. **提交模式低效** — 用户填完所有项才能提交，中途退出数据丢失

新方案将首页重新定义为「打卡页」，移除弹窗，内嵌实时保存，聚焦核心信息。

## What Changes

### 交互模型重构
- 移除 `CheckinModal` 弹窗，打卡表单内嵌到首页
- 所有操作实时保存（Toggle/输入即存），不再需要"提交"按钮
- 体重、饮水、热量、步数嵌入打卡详情区域
- `done` 状态独立控制：仅通过"未完成/已完成"按钮变更

### 页面状态流转

```
State A (草稿)  ──点击 [已完成]──▶  State B (已完成)
                   done→true, 实践/习惯/感悟锁定

State B (已完成) ──点击 [修改打卡]──▶  State C (编辑中)
                   done→false, 实践/习惯/感悟解锁

State C (编辑中) ──点击 [已完成]──▶  State B (已完成)
                   done→true, 实践/习惯/感悟锁定

State B (已完成) ──操作 饮水/热量/体重──▶  State B (不变)
```

### 字段权限矩阵

| 字段 | 草稿 (null) | 编辑中 (false) | 已完成 (true) |
|------|:-:|:-:|:-:|
| 实践 (坐/站/诵) | ✅ 可编辑 | ✅ 可编辑 | 🔒 只读 |
| 习惯 | ✅ 可编辑 | ✅ 可编辑 | 🔒 只读 |
| 感悟 | ✅ 可编辑 | ✅ 可编辑 | 🔒 只读 |
| 💧 饮水 | ✅ 可编辑 | ✅ 可编辑 | ✅ 可编辑 |
| 🔥 热量 | ✅ 可编辑 | ✅ 可编辑 | ✅ 可编辑 |
| ⚖ 体重 | ✅ 可编辑 | ✅ 可编辑 | ✅ 可编辑 |
| 🚶 步数 | — 系统同步 | — 系统同步 | — 系统同步 |

### Banner 设计

Banner 仅做状态 + 统计展示，不再作为打卡入口：
- 左侧：累计打卡天数
- 右侧：连续打卡天数
- 底部：当前打卡状态标识（○未打卡 / ✓已打卡 / ✎编辑中）

### Banner 文案

三态统一使用温暖正向的鼓励语气：

| 状态 | 中文 | English | 繁體中文 |
|------|------|---------|----------|
| draft (未打卡) | 新的一天，开始打卡行动 | A new day, start your check-in | 新的一天，開始打卡行動 |
| editing (编辑中) | 加油，继续今日打卡 | Keep going, continue your check-in | 加油，繼續今日打卡 |
| done (已完成) | 太棒了，今日目标已达成 | Amazing, today's goal achieved | 太棒了，今日目標已達成 |

### 移除的组件
- `CheckinModal` — 弹窗打卡（由首页内嵌替代）
- 首页独立的体重卡片、步数卡片、饮水卡片、热量卡片（嵌入打卡详情）
- Stats 四宫格（累计/连续天数移入 Banner，其他指标移除或移至统计页）
- Streak 独立卡片（合并入 Banner）

### 按钮样式

饮水/热量的添加按钮改为半透明风格：
- 背景色：主题色半透明 (`${P}20`)
- 边框：1.5px 主题色
- 文字：主题色
- 圆角：10px

目标设置入口：饮水/热量行右侧增加 ✏ 编辑 icon，点击弹出目标设置弹窗。

### 字号层级优化

全局调整 `packages/core/src/typography.ts` 字号常量，建立清晰层次：

| 常量 | 原值 | 新值 | 用途 |
|------|------|------|------|
| FONT_LABEL | 16 | 13 | 分区标签（实践/习惯/感悟等） |
| FONT_BODY | 16 | 15 | 正文内容 |
| FONT_BUTTON | 16 | 15 | 按钮文字 |
| FONT_CARD_TITLE | — | 17 | 卡片标题（新增） |
| FONT_TITLE | 18 | 18 | 页面标题（不变） |
| FONT_STAT_CARD | 22 | 22 | 统计数字（不变） |

层级：`13(标签) → 15(正文) → 17(卡片标题) → 18(页面标题) → 22(统计)`

### 保留的组件
- Grace 提醒条（条件显示）
- 添加食物弹窗 `AddFoodModal`（仍需弹窗选择食物）
- 饮水目标设置、热量目标设置弹窗
