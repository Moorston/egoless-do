## Context

当前 `packages/core/src/ai/trail-recommender.ts` 中的 AI 推荐和查询功能存在严重性能问题：

1. **全量数据发送**：每次 AI 调用发送 30 条感念（~3000 字符），模型处理缓慢
2. **无超时控制**：网络不稳定时请求挂起数分钟
3. **无缓存机制**：相同输入重复调用 AI
4. **无降级策略**：AI 失败时直接返回空结果

现有代码结构：
```
packages/core/src/ai/
├── index.ts           # AIService 单例
├── cloud-providers.ts # 云端 AI 提供商
├── local-provider.ts  # 本地 AI 提供商
└── trail-recommender.ts # 推荐和查询逻辑（待重构）
```

## Goals / Non-Goals

**Goals:**
- AI 响应时间从 30-120s 降至 2-5s
- 成功率从 ~50% 提升至 ~90%+
- Prompt 大小从 ~3000 字符降至 ~500 字符
- 提供本地缓存和降级机制

**Non-Goals:**
- 不引入向量数据库或外部嵌入服务
- 不修改 PocketBase 后端
- 不改变现有 UI 交互
- 不支持离线 AI 推理（仍需网络调用云端模型）

## Decisions

### 1. 检索策略：本地多维评分 vs 向量嵌入

**选择**：本地多维评分（关键词匹配 + 情绪权重 + 时间衰减 + 标签匹配）

**理由**：
- 零外部依赖，无需嵌入模型或向量数据库
- 评分逻辑透明可控，便于调试
- 感念数据量级（<1000 条）适合暴力检索
- 可复用现有的 `matchByKeyword` 和 `computeCandidatePool` 函数

**备选方案**：
- 向量嵌入（sentence-transformers）：需要额外依赖，移动端部署复杂
- 全文搜索引擎（MiniSearch）：增加依赖，评分维度单一

### 2. Prompt 精简策略

**选择**：检索 Top-5 相关感念 + 查询上下文摘要

**理由**：
- 5 条感念足够提供语义上下文（覆盖 ~80% 相关性）
- Prompt 从 ~3000 字符降至 ~500 字符，模型处理速度提升 5-6 倍
- 保留查询上下文确保生成结果的相关性

**Prompt 结构**：
```
你是一个思维分析助手。基于以下感念，生成推荐。

用户查询：{query}

相关感念：
1. [{date}] {mood} {content} [标签: {tags}]
2. ...

请生成 JSON 格式的推荐结果。
```

### 3. 缓存策略

**选择**：内存缓存 + TTL（5 分钟）

**理由**：
- 推荐结果在同一会话中短期内有效
- 避免重复调用相同查询
- 内存缓存无需持久化，实现简单

**缓存键**：`sha256(query + sorted(reflectionIds).join(',')).slice(0, 16)`

### 4. 超时与降级

**选择**：10 秒超时 + 本地算法降级

**理由**：
- 10 秒是用户可接受的等待上限
- 超时后自动降级为本地推荐算法（现有 `detectMoodNarrative` 等）
- 用户无感知，体验连续

**降级流程**：
```
AI 调用 → 10s 超时？ → 是 → 返回本地算法结果
                    ↓ 否
              返回 AI 结果
```

### 5. 模型参数优化

**选择**：
- `max_tokens`: 500（推荐结果通常 <300 tokens）
- `temperature`: 0.3（降低随机性，提升一致性）
- 使用轻量模型（如 gpt-3.5-turbo 或同等）

**理由**：
- 减少生成时间
- 降低 token 成本
- 结果更稳定可预测

## Risks / Trade-offs

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 本地检索漏掉相关感念 | 推荐质量下降 | 多维评分覆盖关键词/情绪/时间/标签，降低漏检概率 |
| 缓存结果过期 | 用户看到旧推荐 | 5 分钟 TTL + 手动刷新按钮 |
| AI 超时降级频繁 | 退化为纯本地推荐 | 监控超时率，调整超时阈值 |
| Prompt 过短丢失上下文 | 推荐相关性下降 | 保留查询上下文摘要，Top-5 覆盖主要语义 |

## 数据流

```
用户输入查询
     ↓
┌─────────────────────────────────────┐
│  1. 本地检索（<100ms）              │
│  - 关键词提取                       │
│  - 多维评分排序                     │
│  - 返回 Top-5 感念                  │
└─────────────────────────────────────┘
     ↓
┌─────────────────────────────────────┐
│  2. Prompt 构建（<10ms）            │
│  - 精简感念摘要                     │
│  - 查询上下文                       │
│  - ~500 字符                        │
└─────────────────────────────────────┘
     ↓
┌─────────────────────────────────────┐
│  3. 缓存检查                        │
│  - 命中 → 直接返回                  │
│  - 未命中 → 调用 AI                 │
└─────────────────────────────────────┘
     ↓ (未命中)
┌─────────────────────────────────────┐
│  4. AI 调用（2-5s）                 │
│  - 轻量模型                         │
│  - 10s 超时                         │
│  - 超时降级为本地结果               │
└─────────────────────────────────────┘
     ↓
┌─────────────────────────────────────┐
│  5. 结果处理                        │
│  - 解析 JSON                        │
│  - 写入缓存                         │
│  - 返回推荐                         │
└─────────────────────────────────────┘
```
