## ADDED Requirements

### Requirement: 习惯自动启动
当习惯的开始日期到达时，系统 SHALL 自动将习惯状态从"未开始"变为"进行中"。

#### Scenario: App 启动时自动启动
- **WHEN** App 启动时存在状态为"未开始"且开始日期 <= 今天的习惯
- **THEN** 系统自动将这些习惯状态变为"进行中"

#### Scenario: 零点自动启动
- **WHEN** App 运行中到达零点，存在状态为"未开始"且开始日期 <= 今天的习惯
- **THEN** 系统自动将这些习惯状态变为"进行中"

#### Scenario: 排除已完成习惯
- **WHEN** 存在状态为"已完成"且开始日期 <= 今天的习惯
- **THEN** 系统不改变该习惯状态

#### Scenario: 排除已放弃习惯
- **WHEN** 存在状态为"已放弃"且开始日期 <= 今天的习惯
- **THEN** 系统不改变该习惯状态

#### Scenario: 排除已删除习惯
- **WHEN** 存在已删除且开始日期 <= 今天的习惯
- **THEN** 系统不改变该习惯状态

#### Scenario: 支持 backfill 多天
- **WHEN** App 关闭多天后启动，存在多个习惯的开始日期在过去几天内
- **THEN** 系统自动将所有符合条件的习惯状态变为"进行中"

### Requirement: 状态变更持久化
当习惯状态自动变更时，系统 SHALL 持久化变更到存储。

#### Scenario: 自动启动后持久化
- **WHEN** 习惯状态自动从"未开始"变为"进行中"
- **THEN** 系统将变更持久化到 IndexedDB (web) 或 SQLite (mobile)
